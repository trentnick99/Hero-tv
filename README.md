# HERO TV

Your own TV network, made from the videos you already have. HERO TV turns your movie and show files into channels with
a live TV guide, channel surfing and an on-demand library - on your Windows PC, on your phone, and on a Roku TV.

**HERO TV plays only your own, legally obtained videos. No streams are included; it never fetches, pirates or decrypts
anything (no DRM bypass).** Showtimes are generated by your PC for your own channels - they are not real TV listings.

## Install (Windows 10 / 11)
1. Go to **Releases** (right side of this page) and download `HERO-TV-Setup-vX.Y.Z.exe`.
2. Run it - no administrator rights needed. Windows may say "unknown publisher" because the app is not code-signed:
   *More info > Run anyway*. Tick **Put a HERO TV icon on the desktop**.
3. Click the icon. With no videos yet it starts in demo mode; drag your videos onto the TV window to add them.

After that HERO TV **updates itself**: *Settings (O) > Backup and about > Install now* when a new version is out.
Prefer a zip? Each release also has `HERO-TV-vX.Y.Z-windows.zip` (extract it, double-click `HERO-TV.bat`).
The full guide is in [`README_WINDOWS.txt`](README_WINDOWS.txt).

## What it does
- **Channels and a guide** - Marvel, Spider-Verse, X-Men, DC, South Park, Dragon Ball, horror and more, with a live
  TV guide, channel numbers, an info banner, "Up next" cards and reminders (R in the guide).
- **Fills itself** - drop videos in the Inbox (or onto the window) and they are filed onto the right channels. With a
  free TMDB key it sorts by studio, genre and film series, adds posters and plots, and plays films in release order.
  Shows nobody planned for can get their own channel in one step; fix any mistake with *Move to another channel*.
- **For You** (channel 17) learns from what you watch; **Hero Marathon** follows the clock like real TV (cartoons on
  weekend mornings, hero films in prime time, scary films late at night) and has seasonal specials.
- **Library** - search, resume, favorites, "continue watching", next episode, missing episodes, duplicates.
- **Other screens** - phones and laptops on your WiFi (paired once, watch-only), and a **HERO TV app for Roku TVs**
  that HERO TV installs on the TV for you (guide grid, last channel, start over, reminders).
- **Always on** - can start with Windows and keep running in the background for the Roku app and phones.
- **Help built in** - press `?` for what is wrong and how to fix it; *Report a problem* makes a report to paste into
  a Claude chat; *Check the connection* fixes the usual phone/firewall problems.

## Keys (keyboard or HDMI-CEC remote)
| Key | Action |
|---|---|
| ↑ / ↓ | change channel · 0-9 type a channel number · Backspace previous channel |
| G | TV guide (R in the guide: remind me) |
| H or Esc | home menu · L library · D details · O settings · ? help |
| R | start this show over · C subtitles · S sleep timer · M mute · F fullscreen |

On the Roku remote: Up/Down channel, OK guide, Replay last channel, Rew start over, Fwd back to live, * subtitles.

## Your videos
```
HERO TV media folder/
  Inbox/                                   <- not sure where it goes? drop it here
  MCU/Iron Man (2008).mp4                  <- top folder = the channel's folder
  Marvel Television/Daredevil/Season 1/Daredevil S01E01.mkv
  DC/Superman (1978).mp4
```
Works as is: .mp4 .m4v .mkv .webm .mov with 8-bit H.264 (or VP9 / AV1) video and AAC / MP3 / Opus / FLAC sound. Other
formats (AC-3/DTS sound, 10-bit or HEVC video, .avi) are spotted and can be converted in *Settings > Tools*.
Optional per-video settings go in a `<same name>.hero.json` sidecar (title, year, series, season, episode, tags,
plot, order). Channels live in `config/channels.json` and can be edited in *Settings > Channels*.

## Privacy and safety
- Everything stays on your PC. HERO TV listens only on this computer (127.0.0.1) unless you switch on *Other
  devices* (paired, watch-only devices on your home network) or the TV media server (DLNA; off by default, warned).
- POSTs must be `application/json` and unexpected `Host` headers are refused, so other web pages cannot control it.
- It goes online only for weather, TMDB cover art and smart sorting (with your key), public-domain free movies when you
  ask, and checking this GitHub page for updates (can be switched off). Updates are downloaded only from GitHub over
  verified HTTPS and must match the offered version before they are installed.

## How showtimes work
Schedules are generated per channel from your library, stored in SQLite and kept 48 hours ahead. A restart picks up
exactly where the schedule would be; library changes only re-plan what has not aired yet. Times are stored as UTC and
shown in your timezone, so daylight-saving changes never alter a program. Videos that fail to play repeatedly are
skipped until the next scan.

## For developers
- Python 3.9+ standard library only for the app (`herotv/`); the TV screen is plain HTML/CSS/JS in `web/`; the Roku
  app is BrightScript/SceneGraph in `roku/`. Windows builds use PyInstaller and Inno Setup (`installer/`).
- Tests: `python3 scripts/ci_tests.py` (about 300 unit tests), `scripts/browser_pc_test.py` and
  `scripts/browser_phone_test.py` (Playwright, Chromium and WebKit).
- GitHub Actions (`.github/workflows/windows.yml`) runs everything on Windows and macOS, builds the app and the
  installer, tests installing, updating (including the one-press update) and the firewall check on a real Windows
  machine, compiles the Roku app, and publishes a release when `herotv/__init__.py` has a new version.
- A Raspberry Pi kiosk setup is still included (`scripts/install.sh`), but the Windows app is the main target.

**Not tested on real hardware yet:** the Roku app on an actual Roku TV, AirPlay, and Raspberry Pi playback.
